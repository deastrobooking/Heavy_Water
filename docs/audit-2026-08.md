# Game-Wide Audit — August 2026

Full-codebase audit covering controls/input, UI/modals, enemy & companion AI
lifecycle, and rendering/performance. Four parallel exploration passes produced
the findings below; every HIGH item was fixed in this round, plus the cheap+safe
MEDIUM wins. Remaining MEDIUMs are documented for future rounds.

## Fixed — HIGH severity

### Controls & input
- **Gamepad combo keys stuck after menu open / disconnect** (`GamepadInput.ts`)
  `releaseAll()` never released pending combo-override synthetic keys
  (Quote/Semicolon → Fury Slash / Smash Lash), and `gamepaddisconnected`
  deferred cleanup to the next animation frame (never fires in a backgrounded
  tab). Both now release immediately.
- **Stuck movement keys on focus loss** (`PlayerController.ts`)
  Added centralized `releaseAllKeys()` wired to `blur`, `visibilitychange`
  (hidden), and pointer-lock exit — real keyups swallowed by the OS/browser can
  no longer leave the player running forever.
- **Held keys survive modal open** (`Game.tsx`)
  Opening any menu now drops all held movement/ability keys.

### UI / modal exclusivity
- **Unified modal predicate** (`Game.tsx`)
  `capsuleOpen` and `showLobby` had no refs and were missing from every
  gameplay-input gate (NPCs, rescues, mountain ring, sanctuary/lab side-zones,
  gamepad menu mode). One `isAnyModalOpen()` predicate now feeds all gates.
- **Gameplay input through open menus** (`Game.tsx`)
  Keydown/mousedown/vehicle-input handlers now early-return while any modal is
  open — no more shooting, melee, capture, or turbo through a menu.
- **Armor Capsule had no close path from UI/controller** (`ArmorCapsuleSystem.ts`, `GameUI.tsx`)
  Added public `close()`, a visible ✕ button, backdrop click, gamepad B, and
  inclusion in the unified ESC handler.
- **ESC / Tab inconsistency** (`Game.tsx`)
  ESC now closes *all* modals (capsule/shop/lobby included). Tab is modal-aware:
  closes whatever is open instead of stacking the upgrade menu on top.
- **Shop ignored close actions** (`GameUI.tsx`)
  Gamepad B / ESC / backdrop click now leave the shop like [E].

### AI / entity lifecycle (leaks & stale callbacks)
- **EnemySystem** — death + captain-dome-ring + damage-flash `setTimeout`s were
  untracked; level swaps could fire callbacks against disposed meshes. Now
  tracked per-unit and cancelled on death/dispose/level swap.
- **EnemyBaseSystem** — turret/vault hit-flash timeouts tracked + liveness
  guarded before restoring materials.
- **BioCreatureSystem** — capture orbs targeting despawned creatures are now
  cancelled; orb mesh/material/beam disposed in all teardown paths; creature
  roots disposed explicitly in `dispose()`.
- **CompanionSystem** — heal effect created a new ParticleSystem + Texture per
  tick with nested untracked timers (leaked on level swap): now uses a shared
  texture with tracked effects/timers. Projectile materials leaked per shot:
  now one shared material.

## Fixed — performance (cheap + safe)
- **SkySystem** — per-frame Color3/Vector3 allocations replaced with scratch
  objects; palette/light/fog/uniform recompute throttled to 10 Hz (camera
  follow stays per-frame). Visuals unchanged.
- **CompanionSystem** — squared-distance targeting/collision; reused hit array.
- **BioCreatureSystem** — wander/respawn allocation removal.
- **AerialEnemySystem** — per-frame `filter()` counts replaced with one pass.

## Documented for future rounds (MEDIUM/LOW, not fixed)
- Flight-entry 400 ms triple-jump timer doesn't re-check mounted/dead/swim
  state; flight exit forces "idle" unconditionally; dodge/boost/air-smash flags
  not uniformly cancelled on mount/death/swim/teleport (`PlayerController.ts`).
- Lab/garden capacity read from `baseRef` during render can show stale values
  until an unrelated re-render (`Game.tsx`).
- `ActivePetSystem.syncFromCaptured` allocates sort/filter chains when called;
  worth throttling if profiling shows pressure.
- `InvasionDirectorSystem.chooseInvasionTarget` allocates per decision (rare).
- Enemy FSM `Distance()`/`clone()` scratch-vector conversion (broad, low risk
  per call site — batch with a future enemy-AI round).
- EffectsSystem ring/beam/pillar and ExplosionSystem debris allocate
  mesh/material per event — candidates for pooling.
- Michigan Wilds entry hitch is level-build work at spawn — tracked separately
  as its own task.
- `EnemyBaseSystem.disposeChildren` material ownership could be made explicit/
  idempotent; ally/halo cull nodes should be unregistered on teardown.

## Verification
- `npx tsc --noEmit` clean after all fixes.
- Workflow restart with clean startup logs (see task notes).
- Perf note: the dominant per-frame win is SkySystem (dozens of Color3/Vector3
  allocations per frame → zero steady-state, uniforms at 10 Hz), plus removal
  of per-frame filter/Distance allocations in companion/aerial/bio systems —
  reduces GC pressure that showed up as periodic frame hitches in long combat.
