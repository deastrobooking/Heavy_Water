# 🔥 THE REAL UPGRADE PATH (WHAT YOU ACTUALLY NEED)

## 1. Split Rendering Into Tiers (CRITICAL)

Right now everything is probably treated the same visually. That kills performance.

Create **render classes**:

```ts
type RenderClass =
  | "player"
  | "enemy"
  | "static"
  | "dynamic"
  | "projectile"
  | "effects"
  | "ui3d";
```

Attach to meshes:

```ts
mesh.metadata.renderClass = "enemy";
```

Now your graphics system can:

* enable shadows ONLY for player/enemy
* disable lighting for pickups
* reduce updates for static meshes

## 2. Hook Graphics System Into BabylonEngine

Inside your existing `BabylonEngine.ts`, inject:

```ts
import { DetroitGraphicsSystem } from "./DetroitGraphicsSystem";

export class BabylonEngine {
  private graphics: DetroitGraphicsSystem;

  constructor(canvas: HTMLCanvasElement) {
    this.engine = new BABYLON.Engine(canvas, true);
    this.scene = new BABYLON.Scene(this.engine);
    this.camera = this.createCamera();

    this.graphics = new DetroitGraphicsSystem(
      this.engine,
      this.scene,
      this.camera
    );
  }

  public getGraphics() {
    return this.graphics;
  }
}
```

Now **every system can talk to graphics safely**.

## 4. Fix Your BIGGEST Performance Bottleneck (CityGenerator)

Your city is huge (1200x1200). Right now it's likely:

❌ thousands of meshes
❌ each with materials
❌ each rendered individually

### Replace with batching + merging

Inside `CityGenerator.ts`:

```ts
import { mergeStaticMeshesByMaterial } from "./DetroitGraphicsSystem";

// after generating buildings
const merged = mergeStaticMeshesByMaterial(scene, buildingMeshes, "city");

// IMPORTANT
merged.forEach(m => {
  m.freezeWorldMatrix();
});
```

This alone can give:
👉 **3x–10x performance gain**

## 8. Shadow Strategy (IMPORTANT)

Do NOT give everything shadows.


Everything else:

