## Core idea

Build the character from these layers:

1. **Skeleton**

   * head
   * neck
   * spine
   * pelvis
   * upper/lower arms
   * hands
   * upper/lower legs
   * feet

2. **Base body mesh**

   * generated from capsules, cylinders, lofted sections, or custom `VertexData`
   * proportions controlled by sliders

3. **Clothing layer**

   * jacket torso shell
   * pants shell
   * gloves
   * undershirt

4. **Armor layer**

   * shoulders
   * forearms
   * thigh plates
   * knee guards
   * shin plates
   * boots
   * belt modules

5. **Style layer**

   * hair generator
   * face presets
   * colors/emissives
   * decals/symbols

6. **Animation / posing**

   * driven by Babylon skeleton bones
   * T-pose, idle pose, combat pose

# Native generation strategy

For Babylon-native generation, use these techniques:

## 1. Primitive composition

Good for fast prototyping.

* `MeshBuilder.CreateCapsule`
* `MeshBuilder.CreateCylinder`
* `MeshBuilder.CreateSphere`
* `MeshBuilder.CreateBox`
* `MeshBuilder.ExtrudeShape`
* `MeshBuilder.CreateRibbon`
* `MeshBuilder.CreateTube`

This is ideal for:

* limbs
* torso blockouts
* boots
* armor plates
* belt canisters

## 2. Custom `VertexData`

Use this for:

* stylized face
* anime hair spikes
* jacket lapels
* shoulder armor shells
* segmented knee/shin plates

## 3. CSG / boolean refinement

Use sparingly for:

* cutouts
* vents
* panel recesses
* armor bevel masks

## 4. Parametric attachment system

Every armor/clothing piece should anchor to a named body region:

* `head`
* `chest`
* `pelvis`
* `upperArm.L`
* `upperArm.R`
* `forearm.L`
* `forearm.R`
* `thigh.L`
* `thigh.R`
* `shin.L`
* `shin.R`
* `foot.L`
* `foot.R`

# Best design decision

Do **not** start by trying to generate one continuous perfect human mesh.

Start with a **modular stylized humanoid**:

* body segments
* clothing shells
* armor pieces
* hidden seam zones under armor/clothing

That gives you:

* easier iteration
* better Babylon performance
* easier rigging
* easier part swapping
* easier LOD generation

# Skeleton system

Babylon supports skeletons and skinned meshes, but for a first version you can do this in stages:

## Phase 1

Use a node hierarchy:

* parent meshes to transform nodes for limbs
* pose the character without skinning

## Phase 2

Add a real Babylon `Skeleton`

* bones for each limb
* skinned body mesh
* armor can remain attached rigid meshes

## Phase 3

Add blend/morph features

* face shape presets
* chest/waist/shoulder variation
* hand and foot scaling

# Babylon.js starter implementation

## 1. Character builder entry point

```ts
import * as BABYLON from "@babylonjs/core";
import { CharacterDefinition } from "./CharacterDefinition";
import { buildBody } from "./BodyGenerator";
import { buildArmor } from "./ArmorGenerator";
import { buildHair } from "./HairGenerator";
import { createCharacterMaterials } from "./MaterialFactory";

export function buildHumanoidCharacter(
  scene: BABYLON.Scene,
  def: CharacterDefinition
): BABYLON.TransformNode {
  const root = new BABYLON.TransformNode("characterRoot", scene);
  const mats = createCharacterMaterials(scene, def);

  const body = buildBody(scene, def, mats);
  body.parent = root;

  const armor = buildArmor(scene, def, mats, body);
  armor.parent = root;

  const hair = buildHair(scene, def, mats, body);
  hair.parent = root;

  return root;
}
```

## 2. Body generator

```ts
import * as BABYLON from "@babylonjs/core";
import { CharacterDefinition } from "./CharacterDefinition";

export function buildBody(
  scene: BABYLON.Scene,
  def: CharacterDefinition,
  mats: Record<string, BABYLON.Material>
): BABYLON.TransformNode {
  const root = new BABYLON.TransformNode("bodyRoot", scene);

  const height = def.height;
  const torsoHeight = height * 0.28;
  const legHeight = def.legLength;
  const armLength = def.armLength;

  const pelvisY = height * 0.48;
  const chestY = pelvisY + torsoHeight * 0.55;
  const neckY = pelvisY + torsoHeight;

  const torso = BABYLON.MeshBuilder.CreateCapsule("torso", {
    height: torsoHeight,
    radius: def.chestWidth * 0.22,
    tessellation: 12
  }, scene);
  torso.position.y = chestY;
  torso.material = mats.undersuit;
  torso.parent = root;

  const head = BABYLON.MeshBuilder.CreateSphere("head", {
    diameterX: def.headScale * 0.9,
    diameterY: def.headScale,
    diameterZ: def.headScale * 0.9,
    segments: 16
  }, scene);
  head.position.y = neckY + def.headScale * 0.7;
  head.material = mats.skin;
  head.parent = root;

  const leftUpperArm = BABYLON.MeshBuilder.CreateCapsule("leftUpperArm", {
    height: armLength * 0.45,
    radius: 0.12,
    tessellation: 10
  }, scene);
  leftUpperArm.rotation.z = Math.PI / 2;
  leftUpperArm.position = new BABYLON.Vector3(-def.shoulderWidth * 0.5, chestY + 0.1, 0);
  leftUpperArm.material = mats.undersuit;
  leftUpperArm.parent = root;

  const rightUpperArm = leftUpperArm.clone("rightUpperArm")!;
  rightUpperArm.position.x *= -1;
  rightUpperArm.parent = root;

  const leftThigh = BABYLON.MeshBuilder.CreateCapsule("leftThigh", {
    height: legHeight * 0.48,
    radius: 0.14,
    tessellation: 10
  }, scene);
  leftThigh.position = new BABYLON.Vector3(-def.hipWidth * 0.22, pelvisY - legHeight * 0.22, 0);
  leftThigh.material = mats.undersuit;
  leftThigh.parent = root;

  const rightThigh = leftThigh.clone("rightThigh")!;
  rightThigh.position.x *= -1;
  rightThigh.parent = root;

  return root;
}
```

## 3. Armor generator

```ts
import * as BABYLON from "@babylonjs/core";
import { CharacterDefinition } from "./CharacterDefinition";

export function buildArmor(
  scene: BABYLON.Scene,
  def: CharacterDefinition,
  mats: Record<string, BABYLON.Material>,
  bodyRoot: BABYLON.TransformNode
): BABYLON.TransformNode {
  const root = new BABYLON.TransformNode("armorRoot", scene);

  if (def.armor.shoulders) {
    const leftShoulder = BABYLON.MeshBuilder.CreateBox("leftShoulderArmor", {
      width: 0.5,
      height: 0.25,
      depth: 0.45
    }, scene);
    leftShoulder.position = new BABYLON.Vector3(-def.shoulderWidth * 0.55, def.height * 0.63, 0);
    leftShoulder.material = mats.primaryArmor;
    leftShoulder.parent = root;

    const rightShoulder = leftShoulder.clone("rightShoulderArmor")!;
    rightShoulder.position.x *= -1;
    rightShoulder.parent = root;
  }

  if (def.armor.knees) {
    const leftKnee = BABYLON.MeshBuilder.CreateBox("leftKneeArmor", {
      width: 0.26,
      height: 0.18,
      depth: 0.18
    }, scene);
    leftKnee.position = new BABYLON.Vector3(-def.hipWidth * 0.22, def.height * 0.22, 0.08);
    leftKnee.material = mats.secondaryArmor;
    leftKnee.parent = root;

    const rightKnee = leftKnee.clone("rightKneeArmor")!;
    rightKnee.position.x *= -1;
    rightKnee.parent = root;
  }

  if (def.style.bootType === "heavy") {
    const leftBoot = BABYLON.MeshBuilder.CreateBox("leftBoot", {
      width: 0.28,
      height: 0.22,
      depth: def.footSize
    }, scene);
    leftBoot.position = new BABYLON.Vector3(-def.hipWidth * 0.22, def.height * 0.05, 0.06);
    leftBoot.material = mats.primaryArmor;
    leftBoot.parent = root;

    const rightBoot = leftBoot.clone("rightBoot")!;
    rightBoot.position.x *= -1;
    rightBoot.parent = root;
  }

  return root;
}
```

## 4. Hair generator

For your reference style, use a **strip-based layered hair generator**.

```ts
import * as BABYLON from "@babylonjs/core";
import { CharacterDefinition } from "./CharacterDefinition";

export function buildHair(
  scene: BABYLON.Scene,
  def: CharacterDefinition,
  mats: Record<string, BABYLON.Material>,
  bodyRoot: BABYLON.TransformNode
): BABYLON.TransformNode {
  const root = new BABYLON.TransformNode("hairRoot", scene);

  if (def.style.hairStyle !== "long_spiked") return root;

  for (let i = 0; i < 18; i++) {
    const strand = BABYLON.MeshBuilder.CreatePlane(`hairStrand_${i}`, {
      width: 0.18 + Math.random() * 0.12,
      height: 0.9 + Math.random() * 0.8
    }, scene);

    strand.position = new BABYLON.Vector3(
      (Math.random() - 0.5) * 0.45,
      def.height * 0.82 - Math.random() * 0.2,
      -0.12 - Math.random() * 0.12
    );

    strand.rotation.x = 0.2 + Math.random() * 0.5;
    strand.rotation.y = (Math.random() - 0.5) * 0.8;
    strand.material = mats.hair;
    strand.parent = root;
  }

  return root;
}
```

Later, replace the planes with custom extruded mesh spikes.

# Material setup

```ts
import * as BABYLON from "@babylonjs/core";
import { CharacterDefinition } from "./CharacterDefinition";

export function createCharacterMaterials(
  scene: BABYLON.Scene,
  def: CharacterDefinition
) {
  const make = (name: string, color: string) => {
    const mat = new BABYLON.PBRMaterial(name, scene);
    mat.albedoColor = BABYLON.Color3.FromHexString(color);
    mat.metallic = 0.6;
    mat.roughness = 0.4;
    return mat;
  };

  const skin = new BABYLON.PBRMaterial("skin", scene);
  skin.albedoColor = new BABYLON.Color3(0.9, 0.75, 0.65);
  skin.metallic = 0;
  skin.roughness = 0.9;

  const hair = make("hair", def.colors.hair);
  const undersuit = make("undersuit", def.colors.undersuit);
  const primaryArmor = make("primaryArmor", def.colors.primary);
  const secondaryArmor = make("secondaryArmor", def.colors.secondary);

  return {
    skin,
    hair,
    undersuit,
    primaryArmor,
    secondaryArmor
  };
}
```

# Important engineering choice

Use **two update modes**:

## Rebuild mode

Use when changing:

* body topology
* hairstyle type
* armor type
* jacket type

## Transform mode

Use when changing:

* scale
* color
* attachment visibility
* emissive strength
* pose

This keeps the creator responsive.
