HEAVY WATER — MUSIC FILES
==========================

Drop your MP3 files into this folder using the EXACT filenames below
and the in-game music player will pick them up automatically.

Required filenames (the app probes for these):

  menu.mp3        ← plays on the main menu / opening screen
  track_01.mp3    ← in-game playlist slot 1
  track_02.mp3
  track_03.mp3
  track_04.mp3
  track_05.mp3
  track_06.mp3
  track_07.mp3
  track_08.mp3
  track_09.mp3
  track_10.mp3
  track_11.mp3
  track_12.mp3

You can optionally rename the displayed track titles by editing the
TRACK_TITLES array in client/src/game/MusicSystem.ts.

Missing files are silently skipped — only the tracks that actually exist
will appear in the in-game player UI.
